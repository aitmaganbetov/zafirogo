# Перенос данных MySQL (Laravel Zafiro) → PostgreSQL (zafirogo)

Статус: **заготовка (Этап 0)**. Код — `server/cmd/migrate-from-mysql/main.go`
(пока только печатает план: `go run ./cmd/migrate-from-mysql -club 42`).
Живёт в Go-модуле `server`, чтобы переиспользовать `internal/store` (sqlc) и доменные типы.

## Принцип: поклубно

Клубы переходят по одному (решение владельца, см. `CLAUDE.md`). Пока клуб не перенесён,
он работает на Laravel; после переноса — только на zafirogo. Данные одного клуба
переносятся целиком за одну операцию, остальные клубы не затрагиваются.

## Планируемые шаги

- [ ] Заморозка клуба в Laravel (только чтение по `club_id`), уведомление персонала.
- [ ] Чтение: все тенантные таблицы `WHERE club_id = ?` в одной транзакции `REPEATABLE READ`;
      платформенные справочники — отдельно и один раз.
- [ ] Преобразование:
  - деньги → `int64` тиыны (проверить, в каких колонках MySQL хранятся тенге, а в каких — тиыны);
  - даты → `timestamptz` UTC (учесть часовой пояс клуба из настроек Laravel);
  - статусы/enum → новые значения (таблица соответствия — `docs/schema-changes.md`);
  - пароли пользователей: bcrypt-хеши Laravel проверяются при первом входе и перехешируются в Argon2id.
- [ ] Запись в Postgres одной транзакцией, новые первичные ключи, таблица соответствия
      `legacy_id → id` сохраняется для аудита и повторного запуска.
- [ ] Балансы — не копированием поля, а стартовой проводкой в журнале (ledger)
      «перенос из Laravel» с ключом идемпотентности `migrate:<club_id>:<entity>:<legacy_id>`.
- [ ] Сверка (обязательна, при расхождении — откат): количества строк по таблицам,
      суммы балансов гостей и кассы до тиына, выборочные сессии и чеки.
- [ ] Переключение клуба: DNS/конфиг клуба, переустановка агентов ПК (новый gRPC + mTLS).
- [ ] Повторный запуск идемпотентен: `-dry-run` по умолчанию, запись — только с явным флагом.
