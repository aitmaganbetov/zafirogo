### Роли и права (сервер, а не только интерфейс)

Все GET-эндпоинты без параметров (51) вызваны напрямую токеном каждой роли (гость, владелец, админ, кассир, оператор,
клиент, владелец клуба с истёкшей подпиской). Сверено с `ClubPermissions::SECTIONS` и маршрутами Laravel:

- кассир: касса, клиенты, брони, карта, склад-остатки, заказы, чат, задачи — 200; админпанель, тарифы, склад-каталог,
  услуги, новости, журнал, настройки, работники, подписка — 403 (как `DESK`/`MANAGERS` в Laravel);
- оператор: без кассы (403), остальное как у кассира; кассира и оператора с `/dashboard` интерфейс переводит в кассу
  и к списку ПК (как `DashboardController` Laravel);
- админ: всё, кроме «API и интеграции» (только владелец и `can_manage_integrations`);
- клиент не входит в панель (422, текст Laravel); гость — 401; истёкшая подписка — 402 и переход на `/billing`;
- суперадмин: API только на своём домене (на домене клуба — 404), владелец клуба на домене суперадмина — 403.

## Блокирующий вопрос к владельцу

**Фото товаров.** В Laravel путь фото — `products.image_path` на диске `public` (`storage/app/public/products/…`),
отдаётся как `/storage/<path>` (`ProductResource::imageUrl()`, GS-145/146); загрузки фото в интерфейсе Laravel нет — пути
проставлены вне приложения. В zafirogo картинки хранятся в таблицах базы (Q-085: логотип, экран входа, новости, фото
клуба), диска `public` нет. Путь теперь переносится (миграция 0046), но как хранить и отдавать сами файлы — решение
владельца: (а) таблица `product_images` как у `club_images` и перенос файлов мигратором; (б) файловое хранилище.
Без решения касса и склад показывают заглушку, как сейчас.

## Как повторить

```sh
task gen:check test lint versions:check   # сгенерированный код, юнит-тесты, линтеры
task test:integration                     # Docker
task test:e2e                             # Playwright, мок API
task visual:qa                            # 86 проверок против настоящего сервера стенда tools/visual
```

Playwright без root: недостающие системные библиотеки Chromium (`libatk`, `libatk-bridge`, `libatspi`, `libXdamage`,
`libasound`, `libXRes`) можно распаковать из `apt-get download` в домашний каталог и указать `LD_LIBRARY_PATH`;
с root — `npx playwright install-deps chromium`.
