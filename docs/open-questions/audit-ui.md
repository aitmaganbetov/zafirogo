# Аудит UI и скорости фронтенда (ноябрь 2026) — осознанные отличия и решения

Исправления по аудиту фронтенда (FE-01…FE-23) и дизайна/адаптивности (UI-01…UI-31). Правило — как всегда: дизайн = старый
Laravel, сравнение `task visual` (1440 и 390, порог 0,5 %). Владелец в запросе на аудит потребовал исправить наложения,
переполнения и съезжания на всех экранах — поэтому исправлены и дефекты, унаследованные от старой вёрстки. Там, где такая
правка меняет пиксели на сравниваемых размерах, отличие записано здесь и в `tools/visual/pages.json` (отдельная запись
`<id>-mobile`: порог или `pending` только для телефона; общий порог не менялся — `tools/visual/README.md`).

Снимки «до/после» любой записи: `task visual -- --page <id>` → `tools/visual/report/shots/<id>/<окно>-<тема>/old.png`
(старый Laravel = «до»), `new.png` («после»), `diff.png`.

## Осознанные отличия от старого дизайна (подтвердить)

- [x] **AU-1. Страница не шире экрана телефона на экранах с таблицей и скрытым заголовком «Действия» (UI-01).**
  Было (старый и новый до правки): `span.sr-only` (`position:absolute`) в `<th>` не имел позиционированного предка внутри
  прокручиваемого блока таблицы и растягивал документ: `/users` — 828 px при окне 390 (услуги 461, работники 611,
  тарифы 605, брони 603). Телефон раздвигал окно раскладки: страница уменьшена, окна «Добавить клиента», «Изменить»,
  «Добавить тариф» открывались за экраном, «Сохранить» недоступна. Стало: `relative` на `<th>` (7 мест) — страница 390 px,
  таблица прокручивается в своём блоке. На 1440 пиксели те же. На 390 снимок старого — другого размера (828×2363 против
  390×1113), попиксельно не сравнить: записи `users-mobile`, `services-mobile`, `workers-mobile`, `tariffs-mobile`,
  `tariffs-edit-mobile`, `reservations-mobile` — `pending` (расхождение только в отчёте), настольные записи — как раньше.
- [x] **AU-2. Сетки без `grid-cols-1`: Чат, Заказы, Новости на телефоне (UI-02).** Было: единственная колонка сетки — `auto`,
  растягивалась по `truncate`-тексту или полю выбора файла: `/chat` — 433 px при 390, `/shop-orders` — 404 (суммы и
  «Отменить» обрезаны справа), форма «Новая новость» — поля выходят за правый край карточки (поле выбора файла —
  344 px при карточке 308). Стало: `grid-cols-1` (`minmax(0,1fr)`) — блоки по ширине экрана; полю выбора файла новости —
  `max-w-full`. На чеке (320 px) три действия («В кассу», «Распечатать чек», «Возврат») переносятся на вторую строку вместо
  выхода за экран (на 360 px и шире — одна строка, как раньше). Записи `chat-mobile` (порог 2,5 %; замер 2,1 %), `shop-orders-mobile` (2 %; 1,5 %),
  `shop-orders-all-mobile` (3 %; 2,5 %), `news-mobile` (1 %; 0,85 % в тёмной теме). На 1440 — без изменений.
- [x] **AU-3. X/Z-отчёт на телефоне: таблица прокручивается, а не обрезается (UI-08).** Было: таблица «Сотрудники» 418 px в листе
  378 px (`overflow:hidden`) — колонка «Расход» не видна и недоступна. Стало: `.report-section { overflow-x: auto }` (только
  экран; печать не тронута). На снимках 390 пиксели прежние (0,02–0,03 %): видимая часть та же, остальное — прокруткой.
- [x] **AU-4. Панель управления ПК на телефоне — не выше 40 % экрана (UI-07).** Было: на 320×568 и при масштабе 200 %
  (640×400) панель из 8 кнопок занимала до 75 % экрана и перехватывала нажатия — второй ПК не выбрать. Стало: на ширине
  ≤ 767 px `max-height: 40vh; overflow-y: auto` (кнопки и их перенос те же, лишние строки — прокруткой внутри панели).
  Состояние «ПК выбран» в `task visual` не снимается. Вариант «одна прокручиваемая строка кнопок» не выбран: сильнее меняет
  привычный вид.
- [x] **AU-5. Заголовок страницы в шапке на узком телефоне (UI-12).** На ширине ≤ 360 px часы шапки скрыты — заголовку
  достаётся ~120 px (было «Ад…», «Ка…»); у `h2.admin-title` — `title` с полным текстом. На 390 и шире — без изменений
  (шрифт заголовка не уменьшался: это отличие на сравниваемом размере, не делалось).
- [x] **AU-6. Свёрнутое меню: красная точка у «Чат»/«Заказы» и число в подсказке (UI-16).** В старом счётчик в свёрнутом
  меню был скрыт вовсе (число попадало только в `title="Заказы1"`). Стало: точка 8 px у значка, `title="Заказы (1)"`.
  Свёрнутое меню в `task visual` не снимается.
- [x] **AU-7. Лендинг на 320–360 px (UI-13).** Ссылка «Wiki» в шапке скрыта на ширине < 390 px (есть в подвале), у
  «Попробовать» — `px-3`: кнопки не наезжают на логотип, страница не шире экрана. На 390 и шире — без изменений.
- [x] **AU-8. Страница ошибки внутри панели (UI-04).** В старом 403 — отдельная страница Laravel без оболочки; в новом
  ошибка маршрута рисуется внутри панели. Внутри оболочки: код не ломается в столбик, тёмная тема без белого блока,
  высота — под шапку (без лишней прокрутки), заголовок шапки — «Forbidden»/«Not Found»/«Server Error». Отдельная страница

- [x] **AU-9. Длинное имя клиента (UI-15), длинные тексты (UI-20, UI-25, UI-28).** Имя в таблице «Пользователи» — не шире 16rem
  с многоточием и `title` (было: 60 символов выталкивали баланс и действия за экран). Тело уведомления колокольчика — не
  больше 3 строк (`line-clamp`), полный текст — в `title`. `title` добавлен обрезаемым текстам: превью чата, строка
  заказа, заголовок новости, поле выбора товара на складе.
- [x] **AU-10. Области нажатия на сенсорном экране (UI-14).** Вид не меняется: невидимый псевдоэлемент расширяет область
  нажатия текстовых кнопок и ссылок строк («Изменить», «Удалить», «← Вернуться в кассу» — 17–23 px → 41–47 px) и значков

  «Забыли пароль?», строки «Состояние клуба» дашборда, «Сбросить фильтры». Флажки матрицы прав нажимаются вместе с

  элементов < 40 px — 109 → 68, из них < 24 px — 46 → 14 (остались флажки 13×13 с короткой подписью, поля выбора файла

  пагинация, кнопки форм суперадмина): до порога 40 px им не хватает 1–7 px, а расширение наложилось бы на соседние кнопки.
- [x] **AU-11. Экран второго фактора (новый, UI-18).** Поле кода — цифровая клавиатура; ссылка «Ввести код восстановления»

- [x] **AU-12. График здоровья ПК (новый экран, UI-03).** Высота графика фиксирована (224 px), подписи оси X без наклона

## Поведение без изменения вида

- **UI-05.** Каталог и первая страница витрины кассы загружаются в `loader` маршрута — панель заказа не «прыгает» (CLS).
- **UI-09.** Окна карты клуба и склада (блоки, как в Blade): Escape закрывает, Tab не выходит из окна, фокус возвращается на
  кнопку, которой окно открыли (`web/src/lib/useModalFocus.ts`).
- **UI-10.** Поле выбора товара на складе: Escape закрывает список, стрелки и Enter выбирают.
- **UI-11.** Закрытое мобильное меню — `inert` (не в порядке Tab). **UI-17.** У логотипа меню — пропорции (без сдвига шапки меню).
- **FE-16.** Подписи полей минут в «Настройке клуба» связаны с полями (`htmlFor`); витрина кассы — `<div>`, а не второй `<main>`.

## Скорость — решения

- [x] **AF-1. Предзагрузка по наведению без замены `<a>` на `<Link>` (FE-06).** Разметка из Blade — 86 обычных `<a href>`
  с адресами-строками (пагинация, фильтры, хост кабинета с `rewrite`); типизированный `<Link to>` потребовал бы
  переписать каждую ссылку и её параметры поиска. Вместо этого намерение (наведение ≥ 50 мс, фокус, касание) ловится
  делегированием там же, где клик (`web/src/lib/linkInterception.ts`), и вызывает `router.preloadRoute` — тот же эффект, что
  `defaultPreload: 'intent'` у `<Link>`; DOM и классы не меняются. Индикатора перехода в старом нет — не добавлен.
- [x] **AF-2. Удалены неиспользуемые зависимости (FE-07):** `@hookform/resolvers`, `@tanstack/react-table`,
  `@tanstack/react-virtual` — ни одного импорта (таблицы свёрстаны вручную, как в Blade; длинные списки — с пагинацией).
  CLAUDE.md называет TanStack Table/Virtual в стеке — вернуть одной строкой: `npm i -E @tanstack/react-table@9.3.1
  @tanstack/react-virtual@3.14.24 @hookform/resolvers@6.0.2`. `zod` из единственной формы (новый клиент) заменён
  ручной сборкой тела запроса (−78 КБ в чанке «Пользователи»; эквивалентность — `customers/forms.test.ts`); сам пакет
  оставлен в `package.json` (стек CLAUDE.md: «react-hook-form + zod») — в бандл не попадает, пока не импортирован.
  **Решить владельцу:** оставить `zod` «на вырост» или убрать и его.
- [x] **AF-3. Font Awesome — поднабор (FE-05).** Из того же закреплённого пакета 6.4.0: CSS только используемых иконок и
  три woff2 с их глифами (`web/scripts/gen-icons.mjs` → `web/src/styles/icons/`, результат в репозитории). Новая иконка —
  `npm run gen:icons`; `npm test` падает, если поднабор не покрывает иконки кода (включая значки уведомлений из кода
  сервера и 9 значков зон из CHECK базы). Новая devDependency — `subset-font@2.9.0`.
- [x] **AF-4. Переводы (FE-04, клиент).** Пакет и список языков — в `localStorage` с версией переводов; повторный заход
  рисуется из кэша, пакет перезапрашивается только при смене версии (`GET /api/i18n` → `version`). Первая загрузка идёт
  параллельно с сессией и данными страницы. Адрес пакета — `/api/i18n/{код}?v={version}` (сервер может отдавать его
  с долгим `Cache-Control`). Кэш — только ускорение: нет доступа/повреждён — загрузка с сервера, как раньше.
- [x] **AF-5. События WebSocket склеиваются (FE-02).** `useInvalidateOn`: первое событие перечитывает сразу, остальные за
  1,5 с — одним запросом. Дашборд и список ПК не слушают телеметрию `computer.load`. Данные на этих экранах могут
  отставать от события не более чем на 1,5 с.
- [x] **AF-6. Текст о планировщике в кабинете суперадмина (FE-18).** Было: «…Проверьте строку schedule:run в crontab
  пользователя сервера» (совет про Laravel). Стало: «…Проверьте, что служба сервера Zafiro запущена, и посмотрите её
  журнал» (ru/kk/en в `db/seed/translations-new.*.json`). Длина подобрана так, чтобы число строк на 1440 и 390 не изменилось.
