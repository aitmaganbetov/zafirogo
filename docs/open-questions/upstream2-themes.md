# Перенос ноября 2026 (2): темы ПК и агент — решения исполнителя

Коммиты старого Zafiro `e38b764` (тема ПК клуба), `8094b1d` (карточка входа 380 px), `71db8d6` (ярлык открывает
запущенную оболочку). Решения приняты по принципам `docs/DECISIONS.md` (владелец поручил); описание —
`docs/agent-protocol.md` §15.6.

| ID | Вопрос | Решение | Обоснование |
|---|---|---|---|
| UT-1 | Нужна ли миграция `0042_club_shell_theme.sql`? | **Нет.** Тема — ключ `clubs.settings.club.agent_shell_theme` (jsonb), как в Laravel; перенос из MySQL копирует настройки как есть, инструмент переноса знает ключ и предупреждает о значении не из списка. | Принцип 2: та же модель данных; лишняя колонка дала бы второй источник правды. |
| UT-2 | Как тема доходит до агента? | Цветами в `ClubConfig.shell_theme` (новое сообщение `ShellTheme`, поле 14 — совместимо), `standard` — поле не задано. Push — существующий `ConfigChanged` после сохранения секции `club`. | Как в старом («сервер шлёт сами цвета — новая тема без выпуска агента»); решение 3 ТЗ — новый протокол. Тема применяется сразу, а не «в течение минуты». |
| UT-3 | Где проверять цвета? | Служба (`ShellThemes.Normalize`: все 6 цветов `#rrggbb`, иначе стандартная) и ещё раз страница (`Zafiro.shellThemeVars`) перед `style.setProperty`. | Принцип 4: цвета попадают в CSS; служба — граница доверия к серверу, страница — к мосту. |
| UT-4 | Сохранять тему на ПК? | Да, `shell-theme.pb` в каталоге данных службы (пишется только при смене темы). | Как `AgentConfig.ShellTheme` старого агента: экран входа после перезагрузки сразу в цветах клуба. |
| UT-5 | Рамка поля ввода в фокусе на экране входа | Цвет темы (`--lock-accent`). | В WPF-окне рамку рисовала системная тема; наш перенос раньше взял для неё фиолетовый accent — с темой клуба он был бы чужим цветом. |
| UT-6 | Подсказка «Агент применит тему в течение минуты» | Текст оставлен как в старом (ключ перевода общий). | Принцип 2; утверждение остаётся верным (на деле — сразу). |
| UT-7 | Цвета свотчей на странице настроек | Приходят с сервера (`shell_themes` в `GET /api/settings`, `ShellThemes::swatch()`), названия — переводы на странице. | Один источник цветов для страницы и агента. |
| UT-8 | Ярлык «Zafiro» (`71db8d6`) | Наш UI уже получал сигнал `Local\ZafiroAgent.UI.Launcher`; добавлено: окно уже показано (лаунчер за игрой, экран входа) — вывести вперёд; второй процесс отдаёт право на передний план (`AllowSetForegroundWindow`). Ветки «агент старой версии — MessageBox» нет: старого UI на ПК с новым агентом нет. | Принцип 2 (поведение старого) и решение 5 (без постоянного процесса и опроса). |
