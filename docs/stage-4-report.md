# Этап 4 — итоговый отчёт: интеграции

План — [`stage-4-plan.md`](stage-4-plan.md). Решения по ходу — `docs/open-questions/stage4-*.md`.

## Что сделано

| Блок | Результат |
|---|---|
| Интеграционный API v1 | Все 17 маршрутов `/api/v1` 1:1 со старым: пути, параметры, конверт ошибок, scope ключей, лимиты на ключ и клуб, блокировка IP после неудачных проверок, `Idempotency-Key` (повтор, конфликт, 428), журнал запросов в месячных партициях. Перенесённые ключи интеграторов работают без перевыпуска (тот же SHA-256). Клуб — только из ключа. Вебхуки совпадают со старым форматом и подписью. Справка `/docs/api` показывает спецификацию раздела. |
| Telegram | Клиенты Gateway и Bot API; восстановление пароля в вебе и для гостя на ПК; коды подтверждения перевода баланса (лимиты старого кода, соблюдаются и при параллельных запросах); подключение и проверка токенов в суперадминке; оповещения о сбоях (диск, 5xx, планировщик, клуб офлайн) с антиспамом между инстансами. |
| Мобильные приложения | Слой совместимости со старым REST: 41 маршрут, которые реально вызывают `mobileclient` и `mobileemployee`, формат 1:1. Токены Sanctum (перенесённые сохраняют id — пользователи не разлогиниваются). Во время поклубного перехода новый сервер обслуживает свои клубы и прозрачно проксирует остальные в старый Laravel — без изменений приложений и старого кода (`docs/mobile-compat.md`). |
| Безопасность | Секреты вебхуков и токены Telegram зашифрованы AES-256-GCM со связкой ключей и ротацией; секрет вебхука привязан к клубу; фоновая перешифровка. Утилита и workflow CI подписи обновлений агента Ed25519. Переводы kk/en для всех новых строк и тест покрытия переводов в CI. |
| Эксплуатация | Сроки хранения журналов как в старом (`api_request_logs` — 90 дней, удаление месячных партиций целиком; ledger, аудит и журнал действий не удаляются). |

## Замер mTLS (5 000 потоков агентов)

| | RSS на поток | CPU сервера | Записей в Postgres |
|---|---|---|---|
| без TLS | ≈ 62 КБ | 7,7 % ядра | 0 |
| mTLS, TLS 1.3 | ≈ 97 КБ | 8,5 % ядра | 0 |

Оценка на 50 000 ПК — около 4,5 ГБ памяти.

## Проверка

go vet, golangci-lint, gosec, `go test -race` и интеграционные тесты всех 74 пакетов, sqlc, актуальность
сгенерированного кода, web, миграции up/down/up — зелёные. Интеграционные тесты покрывают сценарии старых Pest-тестов
API v1 (GS-282…345), восстановления пароля и кодов перевода (GS-236…241, GS-521, GS-522), мониторинга
(GS-392…399), приложения сотрудника (GS-274…281) и друзей (GS-099…101).

- Сборка установщика агента в CI (сам агент C# ещё не переведён на новый протокол).
- Мелкие отличия от старого перечислены в `stage4-*.md` (валидация v1 — одна ошибка на поле; опрос чата
  сотрудника — последние 100 сообщений; пагинация приложения сотрудника — по номерам страниц).
