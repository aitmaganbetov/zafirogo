## Найдено и исправлено

- **Безопасность.**
  - Роль базы клубов могла менять платформенные таблицы (суперадмин, релиз агента) → минимальные права (миграция 0028).
  - JSON-тело любого размера читалось до проверки прав (OOM анонимным запросом) → лимит тела.
  - Режим просмотра суперадмина не запрещал запись на 27 маршрутах → общий запрет в роутере.
  - Отдельно исправлены HSTS за прокси, CSP WebSocket, открытый редирект после входа, секреты в DSN в журнале и символические ссылки при переносе файлов.
- **Нагрузка.**
  - Плановая остановка инстанса возвращала ПК обратно на него (7 300 обрывов) → listener gRPC закрывается до Drain, теперь 0 обрывов.
  - Пул Postgres по умолчанию (4 соединения) вставал, когда один инстанс держал все 5 000 ПК → `max(16, 4 × CPU)`.
  - Deadlock счётчиков мониторинга между инстансами → единый порядок записи.
  - Перевод каждого сообщения API открывал транзакцию → строки из памяти.
  - Лимит дескрипторов nginx позволял держать ≈ 2 000 агентов → поднят.
- **Выкладка.**
  - Смена CA агентов обрывала все ПК → прежний CA остаётся в доверии на время ротации.
  - Новые ключи `/api/v1` при переходе клуба уходили не туда → неизвестные ключи сервер сам передаёт в Laravel, карта в nginx не нужна.
  - goose печатал пароль базы → не печатает.
  - Восстановление из копии падало при `max_connections=300` → исправлено.

## Готово, когда — проверка

- Staging поднимается одной командой из образа CI и переживает остановку инстанса без потери операций — **да** (O1, O4).
- Восстановление из бэкапа проверяется автоматически — **да**, `backup-drill` зелёный в CI.
- Дашборды и алерты на ключевые показатели — **да**.
- 5 000 ПК проходят с запасом; ресурсы на 50 000 оценены — **да**. Оценка линейная, без замера на 50 000.
- Находки ревью безопасности исправлены или осознанно приняты — **да**.

## Что нужно от владельца до прода

1. **Инфраструктура прода:**
   - хранилище копий в другом регионе с Object Lock;
   - раздельные учётные записи S3;
   - потоковая реплика Postgres;
   - TLS внутренних соединений, если сеть общая (S6-O1-6);
   - NATS из 3 узлов.
2. **Еженедельные учения на настоящих копиях:** переменная `BACKUP_DRILL_PROD` и self-hosted раннер.
3. **Решения, принятые как в старом:** вход суперадмина без второго фактора (SQ-2), перебор пароля одного аккаунта с многих IP (SQ-1). Пересмотреть — по желанию.
4. **Перенесено с Этапа 5:**
   - проверка агента на Windows 10/11;
   - ключ подписи обновлений и сертификат Authenticode в секретах CI;
   - часовой пояс MySQL на проде;
   - пилот на копии прода.
