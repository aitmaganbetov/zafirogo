# Ревью безопасности (Этап 6, O5)

Дата: 02.11.2026. Объём: сервер Go (`server/`), схема и права Postgres (`db/migrations`), фронт (`web/`), агент C#
(`agent/`), зависимости. Метод — «как атакующий»: для каждой поверхности — путь атаки, проверка кодом или тестом;
находка исправляется с тестом, который падал до исправления, либо принимается с обоснованием.
Решения по спорным пунктам — `docs/open-questions/stage6-security.md` (принципы `docs/DECISIONS.md`, п. 4
«безопасность по умолчанию»).

| SEC-001 | Доступ: режим просмотра суперадмина | medium | Запрет записи в режиме просмотра (Q-054) проверял каждый обработчик: `Access.Routes` — общий middleware, а Public-операции (подключение ПК, интеграции, права сотрудников, уведомления, QR-вход…) — каждая сама. Обход маршрутов (`chi.Walk`) показал 27 изменяющих маршрутов, где запрос суперадмина в режиме просмотра доходил до обработчика; одна забытая проверка в будущем открывает запись в чужой клуб. | **Исправлено**: `readOnlyGuard` в роутере (`server/internal/http/readonly.go`) — любой не-GET к REST в режиме просмотра → 403 `read_only`, кроме кабинета (`/api/superadmin/*`), входа/выхода/refresh и билета WebSocket (как `routeIs('superadmin.*', 'auth.logout')` в Laravel). Тест `TestReadOnlyCannotWriteAnywhere` обходит все маршруты. |
| SEC-002 | Ввод: лимиты тела | high | strict-обработчики oapi-codegen разбирают JSON (`runtime.BindJSONBody` → `json.NewDecoder(r.Body)`) **до** проверки прав и без предела размера. ## Проверено без находок

- **Токены сотрудника**: access — HMAC-SHA256 с kid и меткой домена, срок 10 мин, проверка сессии в Valkey на каждый
  запрос (выход/блокировка — сразу); refresh — ротация с обнаружением повторного использования (Lua, атомарно), отзыв
  семейства; cookie `__Secure-`/`__Host-`, `HttpOnly`, `SameSite=Strict`, CSRF double-submit + Fetch Metadata на refresh
  и logout; access-токен на фронте только в памяти.
- **WebSocket**: одноразовый билет (GETDEL, 30 с, access-токен зашифрован ключом из самого билета), `/ws` за
  `RequireAuth`+`RequireClub`.
- **API-ключи v1**: формат `zfk_`, сравнение хешей `subtle.ConstantTimeCompare`, в журнал — только публичный префикс,
  scope на каждом маршруте (default deny), лимиты окна и размера тела.
- **Старый REST мобильных (Sanctum)**: токен по id + sha256, срок и отзыв, `X-Club-Id` только своего клуба, членство и
  права — как в панели; неизвестный токен уходит на старый Laravel.
- **Гостевые токены агента**: хеш в Valkey, привязка к клубу и ПК сертификата, TTL 12 ч (Q-038).
- **mTLS агента**: цепочка проверяется на рукопожатии (`ClientCAs`), идентичность только из сертификата, отзыв и
  соответствие клубу/ПК — на каждом RPC/потоке, срок сертификата — и для долгих соединений; PROXY protocol только от
  доверенных адресов и от них обязателен; коды регистрации одноразовые (HMAC с перцем), лимит `agent-enroll`.
- **Обновления агента**: Ed25519 по `zafiro-agent-update/v1\nversion\nsha256…`, https и список хостов, размер,
  sha256 файла, файл открыт без записи до запуска; каталог состояния — ACL только SYSTEM и администраторы.
- **WebView2/UI агента**: CSP `default-src 'none'`, без `innerHTML`; мост принимает только методы и схемы
  `IpcMethods`.
- **Деньги**: суммы в тиынах, проверка диапазонов (`MaxTransferAmount`, `MaxShiftAmount`), умножение с проверкой
  переполнения, количество ≥ 1; идемпотентность — отпечаток операции и тела (повтор с другим телом — 409); блокировки
  `FOR UPDATE` в порядке `user_id`.
- **SSRF**: вебхуки — https, публичные адреса (частные, CGNAT, служебные диапазоны запрещены), адрес пришпилен в
  `DialContext`, без прокси и редиректов; Telegram — фиксированный API-хост; манифест релиза — шаблон GitHub.
- **Загрузки**: тип по сигнатуре (только PNG/JPEG), предел размера на поле, имя — сгенерированное, отдача по
  `path.Base` + `nosniff`; статика и wiki — `embed.FS` + `path.Clean`.
- **HTML/XSS**: переводы (редактируются в суперадминке, показываются всем клубам) — только текстом React (без
  `dangerouslySetInnerHTML`/`innerHTML` во всём `web/src`); страница `offline` — `html/template`, тексты в `<script>`
  через `json.Marshal` (экранирует `<>&`), скрипты по sha256 в CSP; ссылки загрузки — только https.
- **SQL**: только sqlc и параметры; `ILIKE` с экранированием `%_\`.
- **IP клиента**: `X-Forwarded-For` только от доверенных прокси (справа налево).
- **Секреты**: тип `config.Secret` (маскируется в логах и `%v`), DSN без пароля в журнале, ошибки 500 без деталей,
  секреты вебхуков — `secretbox` (data keys).
